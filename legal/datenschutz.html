Zugangscode

Die Seite ist derzeit mit einem Zugangscode geschützt. Du gibst den Code auf einer Anmeldeseite ein. Der Server vergleicht ihn nur mit dem hinterlegten Code und speichert ihn nicht. Nach erfolgreicher Eingabe setzt er ein technisch notwendiges Cookie (30 Tage, enthält einen Prüfwert, keinen Klartext-Code), damit Du nicht bei jedem Aufruf neu eingeben musst.

Bewertung von Freitext durch Claude

Nur wenn Du die Freitext-Bewertung nutzt, wird Dein Befundtext zusammen mit den Eckdaten des gezeigten Falls (simulierte Werte, keine Patientendaten) über unseren Server an die Programmierschnittstelle von Anthropic (Anthropic, PBC, San Francisco, USA) gesendet. Lokale Speicherung im Browser

Der Trainer speichert im Browser (localStorage) Deinen Lernstand, das gewählte Niveau, die Sprache, die Einstellung zur Fallvignette und gegebenenfalls Deinen Zugangscode für die Bewertung. Diese Daten bleiben auf Deinem Gerät. Du kannst sie in der Seitenleiste mit „Lernstand löschen“ oder über die Browsereinstellungen entfernen. Außer dem Anmelde-Cookie gibt es keine Cookies, keine Analyse- und keine Werbedienste. Die Schriften werden von der eigenen Domain geladen.

Access code

The site is currently protected by an access code. You enter the code on a login page. The server only compares it with the stored code and does not store it. After a successful login it sets a strictly necessary cookie (30 days, holds a check value, not the code in plain text) so you do not have to enter the code on every visit.

Free-text grading by Claude

Only if you use free-text grading, your report text and the key data of the case shown (simulated values, no patient data) are sent through our server to the API of Anthropic (Anthropic, PBC, San Francisco, USA). The server does not store your text. Please do not put personal data in your report. The legal basis is Art. 6(1)(b) GDPR and your consent by submitting the text (Art. 6(1)(a)). Anthropic's own privacy terms apply on their side.

Local storage in your browser

The trainer stores your progress, chosen level, language, the case history setting and, if you entered it, your access code for grading in your browser (localStorage). This data stays on your device. You can remove it with "Delete progress" in the sidebar or through your browser settings. Apart from the login cookie there are no cookies, no analytics and no advertising services. Fonts are served from our own domain.
